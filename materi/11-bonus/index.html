Nested class dan inner class

Tentukan kapan kelas di dalam kelas lain membutuhkan instans luar.

Pertemuan 11 · Bonus
KonsepSimulasiKuisPraktik

0/2 jawaban benar

Konsep inti

Istilah

Nested class adalah kelas yang dideklarasikan di dalam kelas lain. Member class non-static disebut inner class; static nested class tidak membutuhkan instans luar.

Instans luar

Buat inner class dengan outer.new Inner(). Buat static nested class dengan new Outer.Nested(). Inner class dapat memakai Outer.this untuk merujuk instans luar.

Akses anggota

Inner class dapat mengakses anggota private milik outer. Outer juga bisa mengakses anggota private nested class melalui referensi instans yang tepat. Scope dan kebutuhan referensi objek berbeda dari hak akses.

Organisasi

Nested class dapat mengimplementasikan interface atau memperluas kelas sesuai aturan Java. Compiler umumnya menghasilkan nama file class dengan tanda $, misalnya Outer$Inner.class.

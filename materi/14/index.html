Lab: telusuri dan prediksi

Jalankan satu tahap, amati keadaan, lalu prediksi hasil akhir.

Penyebut valid — try berhasil, catch dilewati, finally berjalan.

int d = 2;
try { System.out.println(10 / d); }
catch (ArithmeticException e) { System.out.println("Penyebut nol"); }
finally { System.out.println("Selesai"); }

Hasil: 5 Selesai

Simulasi terarah. Cuplikan kode tidak dijalankan oleh JVM di browser.

Exception handling

Kenali jenis galat dan pilih cara menangani atau meneruskan exception.

Pertemuan 14
KonsepSimulasiKuisPraktik

0/2 jawaban benar

Konsep inti

Tiga kategori masalah

Galat sintaks terdeteksi saat kompilasi. Galat runtime terjadi saat eksekusi; pembagian int dengan nol menimbulkan ArithmeticException. Galat logika dapat menghasilkan nilai salah tanpa exception.

try dan catch

Tempatkan operasi berisiko dalam try dan tangani kasus yang bisa dipulihkan di catch. Urutkan catch dari tipe lebih spesifik ke tipe lebih umum. Hindari catch kosong.

Checked dan unchecked

IOException adalah checked exception: tangani atau deklarasikan. RuntimeException dan turunannya unchecked. Error umumnya bukan kondisi pemulihan rutin.

finally, throw, throws

finally biasanya dijalankan saat meninggalkan try/catch. Gunakan try-with-resources untuk menutup resource AutoCloseable. throw melempar objek exception, throws menyatakan exception pada signature.

Diagnostik

Baca jenis exception dan stack trace, lalu cari baris pertama dari kode sendiri. NullPointerException, NumberFormatException, dan ArrayIndexOutOfBoundsException memiliki penyebab berbeda.

Prediksi hasil

Pilih skenario dan tebak hasilnya sebelum membuka pembahasan. Potongan kode Java menampilkan hasil yang diharapkan, tanpa menjalankan Java di browser.

int d = 2;
try { System.out.println(10 / d); }
catch (ArithmeticException e) { System.out.println("Penyebut nol"); }
finally { System.out.println("Selesai"); }
Hasil
5 Selesai

try berhasil, catch dilewati, finally berjalan.

int d = 0;
try { System.out.println(10 / d); }
catch (ArithmeticException e) { System.out.println("Penyebut nol"); }
finally { System.out.println("Selesai"); }
Hasil
Penyebut nol Selesai

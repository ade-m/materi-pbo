Input dan output

Konsep 1 dari 4

InputStream membaca byte; OutputStream menulis byte. Reader dan Writer menangani karakter. Untuk teks tentukan charset, misalnya UTF-8.

Sumber: PBO - Pertemuan 14 alt.pdf, hlm. 2–9

Metode penting

Konsep 2 dari 4

InputStream.read() mengembalikan 0–255 atau −1 saat akhir stream. OutputStream.write menulis; flush mendorong data buffered ke tujuan. close menutup resource. OutputStream tidak mempunyai read().

Sumber: PBO - Pertemuan 14 alt.pdf, hlm. 2–9

File dan resource

Konsep 3 dari 4

FileInputStream dan FileOutputStream bekerja dengan file biner. Untuk teks sederhana gunakan Files.readString dan Files.writeString pada Java 11+. Untuk data besar, baca bertahap.

Sumber: PBO - Pertemuan 14 alt.pdf, hlm. 2–9

Overwrite, append, dan galat

Konsep 4 dari 4

Penulisan default dapat mengganti isi file. Untuk menambah, pilih APPEND dan CREATE bila dibutuhkan. Tangani IOException dan gunakan try-with-resources ketika membuka stream sendiri.

Prediksi hasil

Pilih skenario, tebak hasilnya, lalu buka pembahasan.

Path file = Path.of("catatan.txt");
Files.writeString(file, "Halo", StandardCharsets.UTF_8);
System.out.println(Files.readString(file, StandardCharsets.UTF_8));
Hasil
Halo

Penulisan default membuat atau mengganti isi file.

// Isi awal file: Halo
Files.writeString(file, "\nJava", StandardCharsets.UTF_8,
                  StandardOpenOption.APPEND);
System.out.println(Files.readString(file));
Hasil
Halo Java

APPEND menulis di akhir file yang sudah ada.

try (InputStream in = new ByteArrayInputStream(new byte[]{65})) {
  System.out.println(in.read());
  System.out.println(in.read());
}
Hasil
65 -1

Panggilan pertama membaca byte; kedua mencapai akhir stream.

Cuplikan kode dan hasil yang diharapkan; Java tidak dijalankan di browser.

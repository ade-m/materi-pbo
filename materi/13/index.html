Anonymous inner class

Buat implementasi satu kali pakai melalui subclass atau interface tanpa nama kelas baru.

Pertemuan 13
KonsepSimulasiKuisPraktik

0/2 jawaban benar

Konsep inti

Deklarasi dan instans sekaligus

new Tipe(...) { ... } mendeklarasikan kelas anonim sekaligus membuat objeknya. Tipe dasar dapat berupa kelas yang dapat diturunkan atau satu interface yang akan diimplementasikan.

Override dan kontrak

Gunakan @Override untuk memeriksa kesesuaian tanda tangan. Untuk interface, sediakan semua method abstrak yang tersisa. Kelas anonim tidak bisa menuliskan constructor bernama.

Penangkapan variabel

Kelas anonim dapat menggunakan variabel lokal final atau effectively final dari lingkup luar. this di dalam badan kelas anonim menunjuk objek anonim itu sendiri.

Pilih bentuk yang jelas

Gunakan kelas bernama jika perilaku perlu dipakai ulang atau cukup besar. Lambda cocok untuk interface fungsional ketika perbedaan semantik, seperti this, tidak dibutuhkan.

Prediksi hasil

Pilih skenario dan tebak hasilnya sebelum membuka pembahasan. Potongan kode Java menampilkan hasil yang diharapkan, tanpa menjalankan Java di browser.

Runnable r = new Runnable() {
  @Override public void run() { System.out.println("Siap"); }
};
r.run();
Hasil
Siap

Pemanggilan run menjalankan method override; tidak otomatis membuat thread baru.

Object o = new Object() {
  @Override public String toString() { return "Anonim"; }
};
System.out.println(o);
Hasil
Anonim

println memakai toString yang dioverride.

Cek pemahaman

1. Apakah r.run() otomatis membuat thread baru?

2. Variabel lokal yang ditangkap boleh ditugaskan ulang?

Latihan mandiri

Implementasikan Runnable anonim yang mencetak pesan dengan awalan dari variabel lokal. Coba ubah awalan setelah deklarasi dan jelaskan galat kompilasinya.

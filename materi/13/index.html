Prediksi hasil

Pilih skenario, tebak hasilnya, lalu buka pembahasan.

Runnable r = new Runnable() {
  @Override public void run() { System.out.println("Siap"); }
};
r.run();
Hasil
Siap

Pemanggilan run menjalankan method override; tidak otomatis membuat thread baru.

Object o = new Object() {
  @Override public String toString() { return "Anonim"; }
};
System.out.println(o);
Hasil
Anonim

println memakai toString yang dioverride.

Cuplikan kode dan hasil yang diharapkan; Java tidak dijalankan di browser.

Cek pemahaman

Pilih jawaban untuk melihat umpan balik.

1. Apakah r.run() otomatis membuat thread baru?

2. Variabel lokal yang ditangkap boleh ditugaskan ulang?

Kunci dan pembahasan

1. Tidak — run biasa adalah pemanggilan method.

2. Tidak; harus final atau effectively final — Penangkapan variabel lokal mengikuti aturan final atau effectively final.

Konsep 3 dari 5

Kelas top-level public Produk ditempatkan pada Produk.java. Field static dibagi semua instans; field biasa terpisah per objek. Method static tidak memiliki this dan tidak bisa mengakses field instans tanpa objek.

Constructor dan this

Konsep 4 dari 5

Constructor menginisialisasi objek dan tidak punya tipe kembalian. this.harga = harga membedakan field dan parameter. this(...) memanggil constructor lain; pada Java 21 pemanggilan ini harus menjadi pernyataan pertama.

Lab: telusuri dan prediksi

Jalankan satu tahap, amati keadaan, lalu prediksi hasil akhir.

Dua objek, satu penghitung — jumlah milik kelas sehingga kedua constructor mengubah penghitung yang sama.

class Produk {
  static int jumlah;
  Produk() { jumlah++; }
}
// Di dalam main:
new Produk();
new Produk();
System.out.println(Produk.jumlah);

Hasil: 2

Simulasi terarah. Cuplikan kode tidak dijalankan oleh JVM di browser.

Dekomposisi

Konsep 1 dari 4

Pisahkan program menjadi tanggung jawab kecil. Dalam contoh koordinat, kelas Lokasi menyimpan x dan y; kelas App menangani interaksi. Dekomposisi prosedural memecah langkah; dekomposisi objek memecah tanggung jawab.

Array

Konsep 3 dari 4

Array mempunyai panjang tetap setelah dibuat, indeks mulai nol, dan properti length. new int[3] membuat tiga elemen bernilai nol; akses indeks 3 berada di luar batas.

Sumber: PBO - Pertemuan 3.pdf, hlm. 2–22

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 305 / 11

ArrayList

Konsep 4 dari 4

ArrayList dapat bertambah atau berkurang. add menambah, get membaca, set mengganti, remove menghapus, dan size() menghitung elemen. Menyisipkan atau menghapus dapat menggeser indeks. Gunakan Integer untuk menyimpan bilangan bulat sebagai tipe generik.

Sumber: PBO - Pertemuan 3.pdf, hlm. 2–22

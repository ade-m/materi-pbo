Dekomposisi, array, dan ArrayList

Pilih struktur data berdasarkan kebutuhan, lalu amati perubahan indeks dan ukuran.

Pertemuan 3
KonsepSimulasiKuisPraktik

0/2 jawaban benar

Konsep inti

Dekomposisi

Pisahkan program menjadi tanggung jawab kecil. Dalam contoh koordinat, kelas Lokasi menyimpan x dan y; kelas App menangani interaksi. Dekomposisi prosedural memecah langkah; dekomposisi objek memecah tanggung jawab.

Tipe data abstrak

ADT menjelaskan operasi dan perilaku yang terlihat, tanpa mengharuskan pengguna mengetahui penyimpanan internal. Antarmuka List, misalnya, menyatakan operasi koleksi berurutan.

Array

Array mempunyai panjang tetap setelah dibuat, indeks mulai nol, dan properti length. new int[3] membuat tiga elemen bernilai nol; akses indeks 3 berada di luar batas.

ArrayList

ArrayList dapat bertambah atau berkurang. add menambah, get membaca, set mengganti, remove menghapus, dan size() menghitung elemen. Menyisipkan atau menghapus dapat menggeser indeks. Gunakan Integer untuk menyimpan bilangan bulat sebagai tipe generik.

Prediksi hasil

Pilih skenario dan tebak hasilnya sebelum membuka pembahasan. Potongan kode Java menampilkan hasil yang diharapkan, tanpa menjalankan Java di browser.

String[] kota = {"Medan", "Binjai"};
System.out.println(kota[1]);
Hasil
Binjai

Indeks 1 adalah elemen kedua.

List<String> kota = new ArrayList<>(List.of("Medan", "Binjai"));
kota.remove(0);
System.out.println(kota.get(0));
Hasil
Binjai

Elemen berikutnya bergeser ke indeks 0.

List<String> kota = new ArrayList<>(List.of("Medan", "Binjai"));
kota.set(1, "Berastagi");
System.out.println(kota);
Hasil
[Medan, Berastagi]

set mengganti nilai tanpa mengubah ukuran.

Amati pergeseran indeks

Cek pemahaman

1. Apa yang terjadi setelah remove(0) pada daftar dua elemen?

2. Apa cara membaca panjang array a?

Latihan mandiri

Buat daftar tiga kota, sisipkan kota baru di indeks 1, lalu hapus kota pertama. Catat hasil tiap langkah.

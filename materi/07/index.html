Pewarisan dan realisasi interface

Bedakan relasi is-a dan pemenuhan kontrak interface.

Pertemuan 7
KonsepSimulasiKuisPraktik

0/2 jawaban benar

Konsep inti

Generalisasi kelas

Sedan is-a Mobil hanya jika Sedan dapat dipakai di tempat Mobil tanpa melanggar kontraknya. Di Java gunakan extends untuk satu superclass langsung.

Akses dan pewarisan

Subclass dapat menambahkan dan override method instans yang dapat dioverride. Constructor tidak diwariskan. Gunakan super(...) untuk inisialisasi superclass dan akses anggota melalui kontrak yang tersedia.

Realisasi interface

Gunakan implements ketika kelas memenuhi kontrak interface, misalnya Mesin implements Penggerak. Kelas konkret menyediakan implementasi untuk method abstrak yang masih belum dipenuhi.

Notasi UML

Generalisasi memakai garis utuh dan segitiga kosong ke induk. Realisasi memakai garis putus-putus dan segitiga kosong ke interface. Keduanya berbeda dari berlian has-a.

Prediksi hasil

Pilih skenario dan tebak hasilnya sebelum membuka pembahasan. Potongan kode Java menampilkan hasil yang diharapkan, tanpa menjalankan Java di browser.

class Mobil {}
class Sedan extends Mobil {}
// Di dalam main:
Mobil kendaraan = new Sedan();
Hasil
Sedan ──▷ Mobil Generalisasi

Sedan adalah subtipe Mobil.

interface Penggerak { void on(); }
class Mesin implements Penggerak {
  public void on() { System.out.println("Menyala"); }
}
Hasil
Mesin - -▷ Penggerak Realisasi

Mesin menyediakan method public sesuai kontrak.

Mulai dari kebutuhan

Konsep 1 dari 5

Kenali pengguna, tujuan, dan batasan. Susun langkah penyelesaian, tulis kode, uji, debug, lalu pelihara. Untuk petunjuk perjalanan, tentukan titik awal, tujuan, dan kondisi jalan sebelum memilih rute.

Prosedur dan objek

Konsep 2 dari 5

Pendekatan prosedural mengelompokkan langkah dalam fungsi. PBO mengelompokkan data dan perilaku di objek. Program Java dapat memadukan keduanya.

Sumber: PBO - Pertemuan 1.pdf, hlm. 2–3, 5–30

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 104 / 11

Kelas dan instans

Konsep 3 dari 5

Kelas adalah rancangan. Dua objek dari kelas Rekening dapat memiliki saldo berbeda. Enkapsulasi menjaga aturan saldo, abstraksi menyaring detail, pewarisan menyatakan subtipe, dan polimorfisme memungkinkan perilaku berbeda lewat kontrak yang sama.

Sumber: PBO - Pertemuan 1.pdf, hlm. 2–3, 5–30

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 105 / 11

Dari sumber ke eksekusi

Konsep 4 dari 5

JDK menyediakan alat seperti javac. Kompilasi Hello.java menghasilkan bytecode Hello.class; JVM mengeksekusinya. IDE membantu mengedit dan menjalankan kode, tetapi tidak wajib.

Sumber: PBO - Pertemuan 1.pdf, hlm. 2–3, 5–30

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 106 / 11

Java SE dan aplikasi enterprise

Konsep 5 dari 5

Java SE menyediakan fondasi bahasa dan pustaka. Materi sumber juga memperkenalkan JEE, kini Jakarta EE, untuk aplikasi enterprise. Pada sistem bertingkat, peramban mengakses layanan aplikasi; layanan berinteraksi dengan basis data. Cluster dapat membantu kapasitas dan ketersediaan.

Prediksi hasil

Pilih skenario, tebak hasilnya, lalu buka pembahasan.

javac Hello.java
java Hello
Hasil
Halo, Java!

Contoh mengasumsikan Hello.java berisi kelas Hello dengan main yang mencetak pesan tersebut.

javac Hello.java
java Halo
Hasil
Kelas Halo tidak ditemukan

Perintah java mencari kelas yang diminta, bukan nama bebas.

Cuplikan kode dan hasil yang diharapkan; Java tidak dijalankan di browser.

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 108 / 11

Cek pemahaman

1. Apa hasil umum javac Hello.java?

2. Apa contoh objek?

Kunci dan pembahasan

1. Hello.class — javac mengompilasi sumber menjadi bytecode.

2. Rekening milik Dina dengan saldo 50000 — Objek adalah instans konkret yang punya keadaan.

Latihan mandiri

Terapkan konsep pada program Java.

Buat Hello.java, kompilasi dengan javac, dan jalankan dari terminal. Jelaskan peran JDK, JVM, dan IDE. Ketentuan pengumpulan mengikuti instruksi kelas yang berlaku.

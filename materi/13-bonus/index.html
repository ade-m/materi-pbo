Ruang nama

Konsep 1 dari 4

Package mengelompokkan tipe terkait. Penamaan berbasis domain terbalik membantu menghindari tabrakan, misalnya id.ac.kampus.app. Susunan direktori sumber lazimnya mengikuti nama package.

Deklarasi dan import

Konsep 2 dari 4

Deklarasi package mendahului import dan deklarasi tipe. import memungkinkan nama pendek; import java.util.* tidak mencakup subpackage. java.lang diimpor secara implisit.

Library dan classpath

Konsep 3 dari 4

JAR dapat memuat kelas dan resource. import tidak memasang library. Pastikan classpath saat kompilasi dan runtime berisi dependensi yang diperlukan; pengelola build dapat mengurus resolusinya.

Contoh API dan library

Konsep 4 dari 4

API adalah kontrak untuk memakai kemampuan tertentu; library adalah kode siap pakai yang dapat menyediakan API. Swing, JUnit, dan pustaka lain mempunyai tujuan berbeda.

Lab: telusuri dan prediksi

Jalankan satu tahap, amati keadaan, lalu prediksi hasil akhir.

Kompilasi dan jalankan package — Gunakan nama lengkap kelas, bukan nama file sumber.

// src/id/ac/kampus/App.java: package id.ac.kampus;
javac -d out src/id/ac/kampus/App.java
java -cp out id.ac.kampus.App

Hasil: JVM mencari id/ac/kampus/App.class di out

Simulasi terarah. Cuplikan kode tidak dijalankan oleh JVM di browser.

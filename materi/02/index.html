Struktur dan tipe

Konsep 1 dari 5

Deklarasi package dan import mendahului class. main adalah titik masuk contoh terminal. Java memiliki delapan tipe primitif: byte, short, int, long, float, double, char, boolean; String adalah tipe referensi. Field mendapat nilai default, tetapi variabel lokal harus diinisialisasi sebelum dibaca.

Modifier dan konvensi

Konsep 2 dari 5

Gunakan PascalCase untuk kelas, camelCase untuk method/variabel, dan huruf kecil untuk package. private membatasi akses, tanpa modifier berarti satu package, protected juga menyediakan akses tertentu untuk subclass lintas package, public paling terbuka. static milik kelas; final mencegah penugasan ulang.

Sumber: PBO - Pertemuan 2.pdf, hlm. 3–56

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 204 / 12

Ekspresi dan konversi

Konsep 3 dari 5

Urutan operator menentukan hasil; gunakan kurung agar jelas. Pembagian int memotong ke arah nol. Casting double ke int tidak membulatkan; Math.round membulatkan. Konversi pelebaran ke float dapat kehilangan presisi.

Sumber: PBO - Pertemuan 2.pdf, hlm. 3–56

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 205 / 12

String dan masukan

Konsep 4 dari 5

Gunakan equals untuk membandingkan isi String. substring(a,b) mencakup a dan tidak mencakup b. Scanner membaca System.in; argumen CLI tersedia lewat args. Integer.parseInt mengubah teks ke int dan dapat gagal. Gunakan escape seperti \n, \t dan \".

Sumber: PBO - Pertemuan 2.pdf, hlm. 3–56

Mata Kuliah Pemrograman Berorientasi ObjekAde Maulana., S.Kom., M.T.I.Pertemuan 206 / 12

Kendali alur

Konsep 5 dari 5

if dan switch memilih cabang. for cocok saat jumlah iterasi jelas; while memeriksa kondisi di awal, do-while di akhir. break keluar dari loop, continue melewati sisa iterasi, return keluar dari method. Label dapat menargetkan loop luar.

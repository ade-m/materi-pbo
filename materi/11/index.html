Parameter dan argumen tipe

Konsep 2 dari 4

Box<T> mendeklarasikan parameter T; Box<String> memilih String sebagai argumen tipe. new Box<>() memakai inferensi. Gunakan Integer, bukan int, sebagai argumen tipe.

Prediksi hasil

Pilih skenario, tebak hasilnya, lalu buka pembahasan.

Box<String> b = new Box<>();
b.set("Kopi");
String isi = b.get();
Hasil
Kompilasi berhasil; isi = Kopi

T digantikan String untuk pemeriksaan tipe.

Box<String> b = new Box<>();
b.set(42);
Hasil
Galat kompilasi

Nilai int yang di-box menjadi Integer tidak cocok dengan String.

Box<Integer> b = new Box<>();
b.set(42);
int hasil = b.get();
Hasil
Kompilasi berhasil; hasil = 42

Java melakukan boxing dan unboxing untuk int dan Integer.

Cuplikan kode dan hasil yang diharapkan; Java tidak dijalankan di browser.

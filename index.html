Materi PBOAde Maulana, S.Kom., M.T.I.

Pemrograman Berorientasi Objek

Telusuri perubahan program langkah demi langkah, uji prediksi, lalu cek pemahaman di setiap pertemuan.

Materi per pertemuan

  1. Pertemuan 1
    Pengantar PBO dan Java

    Dari masalah sehari-hari ke rancangan kelas dan program Java pertama.

  2. Pertemuan 2
    Elemen dasar Java

    Baca struktur program, prediksi hasil ekspresi, dan telusuri alur kendali.

  3. Pertemuan 3
    Dekomposisi, array, dan ArrayList

    Pilih struktur data berdasarkan kebutuhan, lalu amati perubahan indeks dan ukuran.

  4. Pertemuan 4
    Merancang dan mengimplementasikan kelas

    Rancang kelas dengan keadaan, aturan validasi, dan tanggung jawab yang jelas.

  5. Pertemuan 5
    Diagram kelas, dependency, dan asosiasi

    Bedakan hubungan penggunaan sementara dan hubungan struktural antarkelas.

  6. Pertemuan 6
    Agregasi dan komposisi

    Gunakan aturan kepemilikan dan daur hidup untuk memilih relasi bagian–keseluruhan.

  7. Pertemuan 7
    Pewarisan dan realisasi interface

    Bedakan relasi is-a dan pemenuhan kontrak interface.

  8. Pertemuan 9
    Polimorfisme, kelas abstrak, dan interface

    Prediksi method yang dipanggil dari tipe referensi dan tipe objek saat runtime.

  9. Pertemuan 10
    Java Collections dan iterator

    Pilih koleksi berdasarkan urutan, duplikasi, dan pola akses yang dibutuhkan.

  10. Pertemuan 11
    Kelas generik

    Buat kelas yang dapat dipakai dengan berbagai tipe tanpa casting manual saat membaca nilai.

  11. Pertemuan 11 · Bonus
    Nested class dan inner class

    Tentukan kapan kelas di dalam kelas lain membutuhkan instans luar.

  12. Pertemuan 13
    Anonymous inner class

    Buat implementasi satu kali pakai melalui subclass atau interface tanpa nama kelas baru.

  13. Pertemuan 13 · Bonus
    Package, import, dan library

    Kelola lokasi tipe Java dan tambahkan dependensi tanpa mencampuradukkan import dan classpath.

  14. Pertemuan 14
    Exception handling

    Kenali jenis galat dan pilih cara menangani atau meneruskan exception.

  15. Pertemuan 14 · Alternatif
    Baca dan tulis file Java

    Pilih stream yang sesuai dan bedakan karakter, byte, serta akhir file.
